# Shared Layer

Слой `shared` содержит максимально переиспользуемый код без знания бизнес-сценариев: базовые UI-компоненты, API-обертки, конфигурационные константы и общие утилиты.

Код из `shared` не импортирует верхние слои. Предметные типы находятся в соответствующих сущностях; браузерные утилиты работают с общими структурами и Web API.
