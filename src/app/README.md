# App Layer

Слой `app` отвечает за инициализацию приложения: корневой React-компонент, подключение провайдеров, конфигурацию Redux store, глобальную загрузку данных и поведение уровня всего приложения.

Сюда кладем только код, который нужен для сборки приложения целиком. Бизнес-сущности, самостоятельные пользовательские действия и крупные блоки интерфейса должны жить в `entities`, `features` или `widgets`.
