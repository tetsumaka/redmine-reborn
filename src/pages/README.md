# Pages Layer

Слой `pages` содержит экраны приложения. Страница собирает виджеты, фичи и сущности в готовый пользовательский сценарий.

Страница может хранить локальное состояние конкретного экрана, но не должна становиться местом для переиспользуемой бизнес-логики. Если логика нужна нескольким страницам, переносим ее в `features` или `entities`.
