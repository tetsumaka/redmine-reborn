# Shared Layer

Слой `shared` содержит максимально переиспользуемый код без знания бизнес-сценариев: базовые UI-компоненты, API-обертки, конфигурационные константы и общие утилиты.

Код из `shared` не должен импортировать `app`, `pages`, `widgets`, `features` или конкретные бизнес-сущности без явной причины. Исключение допустимо для типизированных API-контрактов, которые связывают приложение с внешней средой.
