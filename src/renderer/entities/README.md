# Entities Layer

Слой `entities` содержит доменные понятия приложения: запись времени, настройки, данные приложения, задачу Redmine, результат синхронизации.

Сюда кладем типы, selectors, reducers, чистые функции и маленькие UI-представления конкретной сущности. Сущность не должна знать, на какой странице она используется.
