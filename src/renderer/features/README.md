# Features Layer

Слой `features` содержит пользовательские действия и сценарии: добавить запись времени, выбрать период, показать уведомление, синхронизировать данные.

Фича может использовать `entities` и `shared`, но не должна импортировать `pages` или `widgets`. Если код описывает доменный объект сам по себе, ему место в `entities`.
