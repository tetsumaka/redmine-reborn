# Widgets Layer

Слой `widgets` содержит крупные самостоятельные блоки интерфейса: шапку приложения, тулбары, таблицы, аналитические панели и диалоги.

Виджет может собирать несколько `features`, `entities` и компонентов из `shared/ui`, но не должен содержать логику, которая является отдельным пользовательским действием и может переиспользоваться отдельно.
