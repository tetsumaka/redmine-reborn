# Entities Layer

Слой `entities` содержит доменные понятия приложения: запись времени, настройки, данные приложения, задачи и события Redmine, пользовательские фильтры.

Сюда кладем типы, selectors, reducers, чистые функции и маленькие UI-представления конкретной сущности. Сущность не должна знать, на какой странице она используется.

Публичные импорты проходят через `index.ts`, явные связи сущностей между собой — через `@x`.
